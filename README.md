# 💻 Sistema Bancário em Java

Projeto desenvolvido em Java com foco em programação orientada a objetos (POO), simulando operações bancárias básicas.

---

## 📌 Funcionalidades

- Criação de contas (corrente e poupança)
- Depósitos e saques
- Transferência entre contas
- Aplicação de rendimento em conta poupança
- Exibição de dados das contas
- Extrato com histórico de movimentações
- Validação de dados e tratamento de erros

---

## 🧠 Conceitos aplicados

- Programação Orientada a Objetos (POO)
- Herança e polimorfismo
- Encapsulamento
- Estrutura de dados (ArrayList)
- Tratamento de exceções (try/catch)
- Organização em pacotes
- Separação de responsabilidades (classe Banco)
